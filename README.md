# MedCode — Sistema de Gestão de Clínica Médica

Projeto acadêmico desenvolvido em equipe com Java e MySQL, voltado à organização e ao gerenciamento de informações de uma clínica médica.

## Sobre o projeto

O MedCode foi desenvolvido com o objetivo de auxiliar na gestão de uma clínica médica, contemplando módulos relacionados a pacientes, médicos, enfermeiros, consultas e triagem.

## Minha contribuição

Minha responsabilidade no projeto foi o **módulo de Triagem**, trabalhando nas funcionalidades relacionadas a essa etapa do atendimento.

## Funcionalidades e módulos

- Cadastro e gerenciamento de pacientes
- Cadastro e gerenciamento de médicos
- Cadastro e gerenciamento de enfermeiros
- Gerenciamento de consultas
- Módulo de triagem

## Tecnologias utilizadas

- Java
- MySQL
- NetBeans

## Estrutura do projeto

O projeto contém classes Java organizadas em módulos, arquivos de configuração do NetBeans e componentes relacionados à conexão com o banco de dados.

## Contexto acadêmico

Projeto desenvolvido em equipe como atividade acadêmica. Minha participação foi direcionada ao módulo de Triagem.
